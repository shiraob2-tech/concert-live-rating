コンサート・ライブ評価ノート（Android用PWA）

1. ZIPを解凍し、ファイルをHTTPS対応のWebサーバーにアップロードします。
2. Google Cloud ConsoleでGoogle Calendar APIを有効化し、OAuth同意画面と「ウェブアプリ」クライアントIDを作成します。
3. HTTPSサイトのオリジンをOAuthクライアントの「承認済みJavaScript生成元」に登録します。
4. Android Chromeでサイトを開き、クライアントIDを入力してGoogleに接続します。
5. Chromeのメニューから「ホーム画面に追加」または「アプリをインストール」を選びます。

カレンダーは読み取り専用です。予定タイトルに「コンサート」「ライブ」が含まれるものだけを同期します。
アプリ起動後のGoogle接続時と、認証トークンが有効な状態でアプリに戻った際に同期します。
Androidアプリを閉じたままの定期バックグラウンド同期は未実装です。
これはAPKではなくPWAです。評価はブラウザ内のlocalStorageに保存され、クラウドバックアップはありません。
